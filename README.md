# Dubai Night — Telegram Bot

Бот для модерации группы Dubai Night с полным набором функций.

## Возможности

- Приветствие новых участников с фото и автоудалением через 30 секунд
- Фильтр матов (русские + английские слова)
- Удаление пересылок из каналов (для участников)
- ИИ-проверка фото на 18+ (через OpenAI Vision)
- Антиспам (автомут при превышении лимита сообщений)
- Система предупреждений (3 страйка)
- Удаление системных сообщений о входе/выходе
- Логирование событий в отдельный канал
- Команды для администраторов

## Команды администратора

| Команда | Описание |
|---------|----------|
| `/ban @user` | Заблокировать пользователя |
| `/unban @user` | Разблокировать пользователя |
| `/mute @user 30m` | Замутить на время (30m, 2h, 1d) |
| `/unmute @user` | Снять мут |
| `/warn @user` | Выдать предупреждение |
| `/warnings @user` | Посмотреть предупреждения |
| `/resetwarnings @user` | Сбросить предупреждения |
| `/addword слово` | Добавить слово в фильтр |
| `/removeword слово` | Убрать слово из фильтра |
| `/listwords` | Список запрещённых слов |
| `/togglelinks` | Вкл/выкл удаление ссылок |

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ваш-аккаунт/ваш-репозиторий.git
cd ваш-репозиторий/telegram-bot
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить переменные окружения

```bash
cp .env.example .env
```

Открыть файл `.env` и заполнить:

```
TELEGRAM_BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=ваш_id,id_другого_админа
LOG_CHANNEL_ID=id_лог_канала
OPENAI_API_KEY=ваш_ключ_openai
```

### 4. Запустить

```bash
python bot.py
```

## Деплой на Railway (бесплатно, 24/7)

Railway даёт 5$ кредитов в месяц бесплатно — этого хватает для бота.

### Шаг 1 — Загрузить код на GitHub

1. Создайте аккаунт на [github.com](https://github.com)
2. Создайте новый репозиторий (New repository)
3. Загрузите файлы из папки `telegram-bot/`:
   - `bot.py`
   - `requirements.txt`
   - `railway.toml`
   - `Procfile`
   - `welcome.jpeg`
   - `.env.example`

### Шаг 2 — Создать проект на Railway

1. Зайдите на [railway.app](https://railway.app) и войдите через GitHub
2. Нажмите **New Project → Deploy from GitHub repo**
3. Выберите ваш репозиторий
4. Railway автоматически обнаружит Python и установит зависимости

### Шаг 3 — Добавить переменные окружения

В Railway откройте ваш проект → вкладка **Variables** и добавьте:

```
TELEGRAM_BOT_TOKEN = ваш_токен
ADMIN_IDS = ваш_id
LOG_CHANNEL_ID = id_канала
OPENAI_API_KEY = ваш_ключ
```

### Шаг 4 — Готово!

Бот запустится автоматически и будет работать 24/7.

## Получить OpenAI API ключ

1. Зайдите на [platform.openai.com](https://platform.openai.com)
2. Создайте аккаунт
3. Перейдите в **API Keys → Create new secret key**
4. Скопируйте ключ — он начинается с `sk-`

> Если не хотите использовать OpenAI — бот продолжит работать, просто без проверки 18+ фото.
